## Projeto de regressão com Spark.

Projeto de Machine Learning voltado à previsão de preços de imóveis, envolvendo tratamento e análise exploratória de dados, seleção de features, construção de modelos de regressão (Linear, Árvore de Decisão e Random Forest), avaliação de performance, otimização com Cross Validation e ajuste de hiperparâmetros, além da aplicação prática do modelo para suporte à tomada de decisão e previsões em cenários reais.

**Documentação recomendada:**
- https://spark.apache.org/docs/latest/api/python/reference/api/pyspark.ml.regression.DecisionTreeRegressor.html
- https://spark.apache.org/docs/latest/api/python/reference/api/pyspark.ml.regression.LinearRegression.html
- https://spark.apache.org/docs/latest/api/python/reference/pyspark.sql/api/pyspark.sql.DataFrame.randomSplit.html
- https://spark.apache.org/docs/latest/api/python/reference/api/pyspark.ml.evaluation.RegressionEvaluator.html
- https://spark.apache.org/docs/latest/api/python/reference/api/pyspark.ml.regression.RandomForestRegressor.html
